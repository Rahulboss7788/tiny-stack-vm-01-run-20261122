A tiny stack virtual machine in a single `main.ts` (Node 22, no dependencies). One run answers every program of a set: a decode-table dispatch loop over a 256-value stack with 32-bit wrapping arithmetic, a 64-deep call stack and 256 words of memory. All ten traps carry their exact exit codes, under the 1,000,000-step and 65,536-byte output limits. Deterministic.

Run: `node main.ts`.
